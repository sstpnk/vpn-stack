# VPN Stack v1.1.0

## Русский

v1.1.0 - релиз для AmneziaWG 3.1 и связки с Android-клиентом FreedomCat.
Существующие установки по умолчанию остаются в legacy-режиме. AWG 3.1
включается явно через `AMNEZIA_PROTOCOL_VERSION=3.1`.

### Что изменилось

- AmneziaWG Easy теперь собирается на `amneziavpn/amneziawg-go:3.1.20260828`.
- Сервер генерирует клиентские `.conf` с AWG 3.1-полями: `S3`, `S4`,
  `HeaderProtectionKey`, `ContentPaddingAddition`, `RekeyAfterTime`,
  `RekeyTimeout`, `RejectAfterTime`, `KeepaliveTimeout`,
  `MaxHandshakeAttempts`, `RandomTrailers`, `DisableCookies`.
- Runtime-путь AmneziaWG приведен к `/etc/amnezia/amneziawg`.
- Добавлены тесты для AWG 3.1-контракта, API defaults и smoke-проверки
  генерации конфигов.
- README обновлен под текущую сборку; для Android теперь рекомендован
  FreedomCat.

### Обновление

Перед обновлением сохраните текущие `.env`, `data/wg-easy` и
`xray-config/config.json`. Если сервер уже работает в проде, сначала проверьте
AWG 3.1 на отдельном тестовом peer.

```bash
cd /path/to/vpn-stack
git fetch --tags origin
git pull --ff-only origin main
docker compose up -d --build --force-recreate wg-easy vpn-bot xray
docker compose ps
```

После обновления включайте `AMNEZIA_PROTOCOL_VERSION=3.1` только для клиентов,
которые умеют импортировать новый формат. Для Android в этом наборе
рекомендуется FreedomCat.

## English

v1.1.0 adds the AmneziaWG 3.1 server-generated configuration contract and
aligns the stack with the FreedomCat Android client. Existing deployments keep
the legacy behavior by default. AWG 3.1 is enabled explicitly with
`AMNEZIA_PROTOCOL_VERSION=3.1`.

### Changes

- AmneziaWG Easy now builds on `amneziavpn/amneziawg-go:3.1.20260828`.
- Generated client `.conf` files can include AWG 3.1 fields: `S3`, `S4`,
  `HeaderProtectionKey`, `ContentPaddingAddition`, `RekeyAfterTime`,
  `RekeyTimeout`, `RejectAfterTime`, `KeepaliveTimeout`,
  `MaxHandshakeAttempts`, `RandomTrailers`, and `DisableCookies`.
- The AmneziaWG runtime path is aligned to `/etc/amnezia/amneziawg`.
- Test coverage was added for the AWG 3.1 contract, API defaults, and config
  generation smoke checks.
- README guidance was refreshed; FreedomCat is now the recommended Android
  client for this stack.

### Upgrade

Preserve `.env`, `data/wg-easy`, and `xray-config/config.json` before upgrading.
On production servers, validate AWG 3.1 with a separate test peer first.

```bash
cd /path/to/vpn-stack
git fetch --tags origin
git pull --ff-only origin main
docker compose up -d --build --force-recreate wg-easy vpn-bot xray
docker compose ps
```

Enable `AMNEZIA_PROTOCOL_VERSION=3.1` only for clients that can import the new
format. FreedomCat is the recommended Android client for this stack.
